|Script| Description |
|------|-------------|
|`pnpm dev`| Starts the development server.|
|`pnpm build`| Builds the application for production.|
|`pnpm fmt`| Runs the code formatter in check mode.|
|`pnpm fmt:write`| Runs the code formatter and writes changes to files.|
|`pnpm validate`| Runs all validation scripts.|
|`pnpm validate --watch`| Runs all validation scripts in watch mode.|
|`pnpm declutter`| Runs the declutter script in check mode.|
|`pnpm declutter:write`| Runs the declutter script and writes changes to files.|
|`pnpm check`| Runs all checks. |
